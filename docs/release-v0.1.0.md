# HuTao Companion v0.1.0

首个可运行的本地预览版本，面向 Windows 10/11 x64。

## 本版内容

- 完整聊天窗口缩小为 `350 × 480`，支持完整聊天、头像气泡、完全隐藏三种显示模式。
- 头像模式仅显示当前角色头像和最近一条角色气泡，可拖动、双击恢复完整窗口。
- 增加系统托盘入口，可在完全隐藏后恢复窗口、切换显示模式、控制置顶或退出。
- 使用 WPF `Topmost` 与 Windows `SetWindowPos(HWND_TOPMOST)` 保持普通桌面场景下的前台层级，置顶时不主动抢夺输入焦点。
- 支持胡桃、芙宁娜、可莉角色切换，以及独立人设、主题、声线配置与聊天记录。
- 支持 DeepSeek 对话、ReAct 环境工具、胡桃记忆彩蛋、原始游戏短台词优先和 GPT-SoVITS 常驻推理。
- 支持 TXT/DOCX 分段、情绪规划、角色声线朗读及 MP3 合并。
- 完整包内置 GPT-SoVITS v3、便携 Python/PyTorch、模型权重、FFmpeg、三角色参考/原声音频及剧情 RAG 数据，只有 DeepSeek API Key 需要使用者自行填写。

## 使用提示

- 首次直接运行 `run.bat` 即可；便携 Python 会自动适配当前目录，模型首次加载会比后续对话更慢。
- 使用 DeepSeek 时，将 `.env.example` 复制为 `.env` 并填写 `DEEPSEEK_API_KEY`。
- 未填写 API Key 时界面仍可运行，但对话使用离线 Mock；其他本地运行资源均已包含。
- Windows 的全屏独占程序、UAC 提权界面和安全桌面可以覆盖普通置顶窗口，这是操作系统边界。
